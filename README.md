# CICBuster

El siguiente proyecto es acerca de una simulación tipo cine como si fuera parte del cic y su catalogo de rentas de pelicula, este proyecto emplea nuestros conocimientos sobre HTML y CSS (Segundo Parcial).

## Descripción

Una explicación más detallada del proyecto. Aquí puedes mencionar:
La motivación principal fue el extenso catalgo de peliculas que ofrece el CIC de UMAD.
Y queerer realizar una similitud en el formato de las peliculas con el extinto formatio blockbuster

## Tecnologías Utilizadas

- HTML5
- CSS3
-Normalize

## Requisitos Previos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Editor de código (recomendamos VS Code)

## Instalación

1. Clona este repositorio:

  -  git@github.com:Guaguen/Cicbuster-Proyecto.git


2. Navega a la carpeta del proyecto:

   - CICBuster-royecto


3. Abre el archivo `index.html` en tu navegador

## Uso

Explica cómo usar tu proyecto:

1. Abre `index.html` en tu navegador
